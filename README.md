# My Letters v1.0

## About
  You can create a pdf letter and send it to your friends, family or favourite people.

  To create a pdf letter, you need to: 
  - Pick up a template.
    > You can find the templates in the **Templates** folder.
  - Fill in the template with your own content.
    > Write your content in the letter and upload a picture or photo if you want.
  - Save the letter as a pdf file.
    > Download the pdf file and share it.

## Project setup

```
npm install
```

### Compiles and hot-reloads for development

```
npm run dev
```

### Compiles and minifies for production

```
npm run build
```
